= Cheatsheet

For your convenience, this page contains access information to all systems in your lab environment.

== Lab Login

Your lab user, for example `user35`, is on the slip of paper you got at the start. Your instructor tells you the initial
password. On your first login, you set your own password. Your workspace in Red Hat OpenShift Dev Spaces is already created for you.

TIP: Log in in a *private browser window*. Cookies left over from another lab can sign you in with the wrong account.

== Environment checks

=== Check the image build service

[source,sh,role=execute]
----
caib status
----

=== Check your OpenShift identity

[source,sh,role=execute]
----
oc whoami
----

=== Authenticate to Jumpstarter

[source,sh,role=execute]
----
jmp-login
----

NOTE: Copy the printed URL with *Ctrl+Shift+C*, open it in a browser, and click *Yes* on the
*Grant Access to jumpstarter-cli* page.

=== List all Exporters (also checks your Jumpstarter login)

[source,sh,role=execute]
----
jmp get exporters
----

== Flash and boot a device

=== Lease an Exporter

[source,sh,role=execute]
----
jmp shell -l device=qemu
----

=== List hardware interfaces exposed on the Exporter

[source,sh,role=execute]
----
j
----

=== List available OS images

[source,sh,role=execute]
----
caib image list
----

=== Flash and boot the device

[source,sh]
----
DISKIMAGE=<uri from caib image list>
----

[source,sh,role=execute]
----
j flasher flash oci://$DISKIMAGE
----

[source,sh,role=execute]
----
j power on && j console start-console
----

Log in as `root` with password `password`.

=== Leave the serial console

Press *Ctrl+B* three times.

=== Release the lease

[source,sh,role=execute]
----
exit
----

== On the device

=== List containers in the root partition

[source,sh,role=execute]
----
podman ps
----

=== Follow the engine service log

[source,sh,role=execute]
----
journalctl -f -u engine
----

Press *Ctrl+C* to stop following a log.

=== Show all processes with their SELinux labels

[source,sh,role=execute]
----
ps axfZ
----

=== List the communication sockets shared between the partitions

[source,sh,role=execute]
----
ls -l /run/ipc/vsomeip/
----

=== Get a shell in the QM partition

[source,sh,role=execute]
----
podman exec -it qm /bin/bash
----

Leave it again with `exit`.

=== Start the radio client (inside the QM partition)

[source,sh,role=execute]
----
podman exec -it systemd-radio radio-client
----

Volume: *+* / *-*, next station: *SPACE*, radio on/off: *ESC*, quit: *Q*.

=== List the processes of the QM partition (inside the QM partition)

[source,sh,role=execute]
----
ps axl
----
