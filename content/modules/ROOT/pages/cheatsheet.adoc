= Cheatsheet

For your convenience, this page contains access information to all systems in your lab environment.

== Lab Login

Your lab user, for example `user35`, is on the slip of paper you got at the start. Your instructor tells you the initial
password. On your first login, you set your own password.

Login sequence: *Log in with OpenShift* -> *AutomotiveSuite* (not *OpenShift*) -> lab user and password -> new password
(first login only) -> *Allow selected permissions*.

TIP: Log in in a *private browser window*. Cookies left over from another lab can sign you in with the wrong account.

== Flash and boot a device

=== Lease an Exporter

[source,sh,role=execute]
----
jmp shell -l device=qemu --duration 1h
----

The lease ends after one hour and the shell closes by itself. Lease, flash, and boot again to continue. Set
`DISKIMAGE` again first: the variable is lost together with the old shell.

=== List hardware interfaces exposed on the Exporter

[source,sh,role=execute]
----
j
----

=== List available OS images

[source,sh,role=execute]
----
caib image list
----

=== Follow the build log of an image

[source,sh]
----
caib image logs <image name from caib image list>
----

=== Flash and boot the device

[source,sh]
----
DISKIMAGE=<uri from caib image list>
----

[source,sh,role=execute]
----
j flasher flash oci://$DISKIMAGE
----

[source,sh,role=execute]
----
j power on && j console start-console
----

Log in as `root` with password `password`.

=== Leave the serial console

=== Start the radio client

[source,sh,role=execute]
----
podman exec -it qm podman exec -it systemd-radio radio-client
----

Volume: *+* / *-*, next station: *SPACE*, radio on/off: *ESC*, interference monitor on/off: *M*, quit: *Q*.

=== Put the QM partition under CPU load, watch, and stop it

Set up the two tmux panes first, see <<tmux-script>>. Open the interference monitor with *M* in the radio client, then
start the load:

[source,sh,role=execute]
----
podman exec qm systemctl start sysbench
----

Optional, to see the CPU usage from the operating system's side (quit with *q*):

[source,sh,role=execute]
----
top
----

Stop the load:

[source,sh,role=execute]
----
podman exec qm systemctl stop sysbench
----

=== Check the engine log of the last 10 minutes

[source,sh,role=execute]
----
journalctl -u engine --since "-10 min" --no-pager
----

=== Optional: get a shell in the QM partition

[source,sh,role=execute]
----
podman exec -it qm /bin/bash
----

Leave it again with `exit`.

[#tmux]
=== tmux: split the serial console

`tmux` is installed on the device. It splits the serial console into several panes, so that you can watch several
things side by side, for example the radio client and a command prompt. Start it on the device:

[source,sh,role=execute]
----
tmux
----

All tmux keys start with *Ctrl+B*. Press *Ctrl+B*, release both keys, and then press the second key:

[cols="1,3",options="header"]
|===
|Keys |What it does

|*Ctrl+B*, then *"*
|Split the current pane into an upper and a lower half

|*Ctrl+B*, then *%*
|Split the current pane into a left and a right half

|*Ctrl+B*, then an arrow key
|Move to the neighboring pane in that direction

|*Ctrl+B*, then *z*
|Zoom the current pane to the full window, and back again

|*Ctrl+B*, then *[*
|Scroll mode: scroll back with the arrow keys or *Page Up* / *Page Down*. Press *q* to leave it.

|*Ctrl+B*, then *x*
|Close the current pane, confirm with *y*

|*Ctrl+B*, then *d*
|Detach: leave tmux, while the programs in the panes keep running. Run `tmux attach` to get them back.

|`exit`
|Close the current pane. Closing the last pane ends tmux.
|===

WARNING: Pressing *Ctrl+B* three times in a row quits the Jumpstarter serial console. In tmux, press *Ctrl+B* only once
before each key.

==== Mouse mode

To use the mouse in tmux, turn on mouse mode. Run this in any pane:

[source,sh,role=execute]
----
tmux set -g mouse on
----

Now you can click a pane to select it, drag the border between panes to resize them, and scroll with the mouse wheel.
To select text for copying while mouse mode is on, hold *Shift* (on macOS: *Option*) while you select it. If that
does not work, turn mouse mode off again:

[source,sh,role=execute]
----
tmux set -g mouse off
----

[#tmux-script]
==== Layout for the CPU load step

Paste this script into the serial console. It starts the radio client in the upper pane and leaves you in the lower
pane, with the command that starts the load shown as a comment:

[source,sh,role=copypaste]
----
SESSION=autosd-demo
tmux new-session -d -s $SESSION -n "Autosd Demo"
tmux split-window -v -t $SESSION:0
tmux send-keys -t $SESSION:0.0 "podman exec -it qm podman exec -it systemd-radio radio-client" C-m
tmux send-keys -t $SESSION:0.1 "# podman exec qm systemctl start sysbench" C-m
tmux select-pane -t $SESSION:0.1
tmux attach-session -t $SESSION
----

Close the whole session, including the radio client, from any pane:

[source,sh,role=execute]
----
tmux kill-session -t autosd-demo
----

If you detached with *Ctrl+B*, then *d*, get the session back with:

[source,sh,role=execute]
----
tmux attach-session -t autosd-demo
----
