= Conclusion

During the workshop, you have learned how to:

- work in a prepared cloud development environment in Red Hat OpenShift Dev Spaces, connected to the Red Hat Automotive Suite.
- lease a test device with Jumpstarter, flash a Red Hat In-Vehicle OS (RHIVOS) image onto it, and boot it.
- tell the root (ASIL) partition and the QM partition apart, and see how they isolate workloads of different criticality.
- read an image manifest, and follow how a pipeline builds, flashes, and tests every change automatically — on a virtual device today, and on physical hardware with the same tools.
