== Overview

https://jumpstarter.dev/[Jumpstarter,window=_blank] is an open source framework for testing software on hardware and on
virtual devices. Hardware-in-the-loop (HIL) testing has long been done with expensive proprietary systems; Jumpstarter
brings it to everyone with a free, cloud-native approach.

In the Red Hat Automotive Suite, Jumpstarter connects developers and pipelines to their test devices. The same commands
work for a virtual QEMU device and for a physical board: in this lab, you use them on a virtual device, and your
instructors use them on an ARM board.

Jumpstarter is written in Python and works with common tools such as https://docs.pytest.org/en/stable/[pytest,window=_blank],
shell scripts, Makefiles, and CI/CD systems.

[#jmp_components]
== Core components

You meet these terms in the lab:

- **Device Under Test (DUT)** - The hardware or virtual device being tested.
- **Exporter** - Makes a device and its interfaces, such as power, serial console, and flasher, available over the
  network. In this lab, every virtual device has its own Exporter.
- **Client** - The `jmp` command-line tool and libraries you use to work with a device.
- **Lease** - Reserves an Exporter for you for a limited time. Nobody else can use it until the lease ends.
- **Service** - The controller on OpenShift that manages access to the Exporters and hands out leases.

Behind the Exporters, *drivers* talk to the hardware connections of the device, and *adapters* convert them for
special use cases. All communication runs over gRPC.

More detail is in the https://jumpstarter.dev/index.html[Jumpstarter documentation,window=_blank], and the
https://github.com/jumpstarter-dev/jumpstarter[source code,window=_blank] is on GitHub.
